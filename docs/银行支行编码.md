# 银行支行编码查询

## 数据源

项目根或 `data/` 下的 **`银行支行编码.xlsx`**

| 列名 | 含义 | 查询字段 |
|------|------|----------|
| 联行号 | 12 位支付系统行号 | 精确匹配 / 关键字 |
| 联行名称 | 支行全称 | 关键字、地名（省市） |
| 总行银行号 | 总行编码 | 展示 |
| 总行银行名称 | 总行名称 | 银行筛选 |

当前表约 **15.3 万** 条、**四千** 余家总行名称。

## 导入

```powershell
cd D:\projects\tool
npm install   # 需 xlsx（import 用）
npm run import:cnaps
```

生成：

- `data/cnaps-full.jsonl` — 查询主库  
- `data/cnaps-full.meta.json` — 条数、银行列表等  
- `data/银行支行编码.xlsx` — 源表归档副本  

API 首次查询时把 jsonl 载入内存（约数秒，进程内缓存）。

## 批量与激活码

H5：`/bank/batch` — 多行查询 + CSV，需客服发放的激活码（按次 / 包月 / 包季）。详见 [批量查询与激活码.md](./批量查询与激活码.md)。

## 查询用法

H5：`/bank` 或 `/local-bank`（临沂关键字预填）

API：

```
GET /api/v1/info/bank/cnaps?bank=工商银行&keyword=临沂
GET /api/v1/info/bank/cnaps?keyword=102473000015
GET /api/v1/info/bank/meta
```

省市：表中无独立省市列，接口用 **联行名称** 包含匹配（如 `city=临沂`）。

本地网点地点核实：见 [本地银行网点核实.md](./本地银行网点核实.md)。地图标注：见 [本地银行网点地图.md](./本地银行网点地图.md)（`AMAP_WEB_KEY` + `/local-bank`）。

## 说明

联行号会变更，数据仅供参考，正式汇路以银行柜台 / 网银为准。源表**无门牌地址、无经纬度**。
