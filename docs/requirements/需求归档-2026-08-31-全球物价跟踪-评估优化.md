## 0. 一句话结论

**可做，但禁止做成「一个页面塞四盘行情 + 随便填价」。**  
推荐：**官方行情（只读、可归因）与 UGC 民价（可写、强治理）分轨**；首期只做 **中国可读的民生篮 + 延迟外汇/贵金属现货 + 有限大宗现货/指数**，全球深度与实时交易级行情列为非目标。

## 2. 三专家评估

### 2.1 软件架构专家

#### 问题诊断

| 风险 | 说明 |
|------|------|
| 异构域硬揉 | 期货点价、央行中间价、农贸批发、超市小票价 **时间粒度·币种·单位·场所** 全不同，单表 `prices` 会崩 |
| 抓取债 | 现有菜蛋肉价靠 HTML 解析商务预报；扩到全球交易所会触发 ToS、IP、验证码、断源 |
| UGC 写路径 | 无审核 = 广告/套利刷价；无去重 = 同城同品噪声 |
| 实时幻想 | 浏览器「全球跟踪」若暗示 tick 级，成本与合规远超实用查体量 |

#### 推荐架构（分层）

```text
[Providers]  适配器：MOFCOM · FX mid · metals spot · commodities delayed
     ↓ ingest (cron / queue)
[Quote Store]  quotes_latest · quotes_history · instrument_meta
     ↓
[Read API]     /api/v1/prices/{book}/…   book = fx|metals|commodities|livelihood
     ↓
[Web]          四书签 + 对比卡（显式「数据级」徽章）

[UGC]          POST submissions → moderation → published_local_prices
               与 Quote Store 物理隔离；前台用虚线/「网友」标
```

**核心契约建议**

| 实体 | 关键字段 |
|------|----------|
| `instrument` | id · book · symbol · name_zh · unit · currency · venue · delay_sec · source |
| `quote` | instrument_id · as_of · bid/ask/mid/last · change_pct · ingest_at |
| `ugc_price` | sku_id · city_id · place_type · price · currency · unit · reported_at · status · reporter_hash |

**首期技术选型（贴合 tool 现状）**

- 继续 Node API + Vue H5；行情入库优先 **JSON/SQLite**，历史序列再上 PG
- Provider 适配器插件化；**禁止**在 View 里直接 `fetch` 外站
- 缓存：官方轨 TTL 按书签（外汇 1h、贵金属 15–60m、民生日更）
- 观测：`prices.view` · `ugc.submit` · `provider.error`

#### 架构结论

| 项 | 做 / 缓 / 不做 |
|----|----------------|
| 四书签 IA + 统一 `instrument` 元数据 | **做** |
| Provider 适配器 + 短缓存只读 API | **做** |
| UGC 审核队列 + 城市/SKU 白名单 | **做**（可先人工 Admin） |
| WebSocket 实时推送 / 自建行情中台 | **不做**（首期） |
| 多交易所全品种爬虫 | **不做** |
| 把 UGC 写入官方 quote 表 | **不做** |

### 2.2 经济学家

#### 概念澄清（必须写进产品文案）

| 用户口语 | 实际应展示 | 误用后果 |
|----------|------------|----------|
| 「物价」 | 常指 **消费端/民生篮**（近似 CPI 成分） | 与期货混谈会误导通胀感知 |
| 「大宗」 | **工业/能源/农产品原料** 现货或期货 | 原油涨 ≠ 下周菜价同幅涨 |
| 「贵金属」 | 金/银等 **资产与工业双属性** | 当「保值必然」叙事有风险 |
| 「外汇」 | 汇率是 **相对价格** | 人民币升值 ≠ 国内物价下降同比例 |

#### 产品含义建议

1. **民生篮（Livelihood Basket）**：固定 SKU（米油肉蛋奶菜油燃料），城市对比；强调 **名义价 + 单位统一（元/kg 等）**。
2. **宏观参照轨**：可选挂「上年同月 / 周环比」；**不做**自建 CPI（样本偏差不可控）。
3. **传递机制教育（轻量）**：一页「为何原油≠菜价」短说明即可，不做长文科普站。
4. **PPP / 实际汇率**：首期 **缓**；需要购买力平价才做「全球汉堡指数」类玩法。

#### 经济结论

| 项 | 做 / 缓 / 不做 |
|----|----------------|
| 固定民生 SKU 篮 + 城际对比 | **做** |
| 官方批发（商务预报）作民生「批发锚」 | **做**（已有） |
| UGC 零售作「体感锚」并与批发分列 | **做** |
| 自称「民间 CPI / 官方替代指数」 | **不做** |
| 用期货结算价直接当「全球物价指数」首页大数 | **不做** |

### 2.3 市场分析师

#### 四盘怎么排、用什么源（务实）

| 书签 | 用户刚需 | 首期标的建议 | 数据级 | 源策略 |
|------|----------|--------------|--------|--------|
| **外汇** | 出行/跨境电商心智 | USD/CNY · EUR/CNY · JPY/CNY · 少数跨境常用 | 延迟中间价 | 央行/公开中间价或合规延迟 API |
| **贵金属** | 金价心智 | Au · Ag（人民币/克 + 美元/盎司双显） | 延迟现货 | 公开现货/交易所延迟；禁伪「实时成交」 |
| **大宗** | 油/铜/大豆情绪 | 原油（Brent/WTI 选一主显）· 铜 · 大豆/螺纹 等 **≤8 个** | 日更或延迟 | 付费延迟 API 或人工日更 JSON；忌全市场 |
| **民生** | 买菜/过年 | 现有菜蛋肉 + 油价 + UGC 零售试点 | 日更批发 + UGC | 商务预报 + 油价 JSON + 填报 |

#### 互动填报（市场视角）

- **只开民生零售**：大宗/外汇/贵金属 **禁止** 网友改行情（操纵与合规雷区）。
- 填报字段最小集：`城市 · 品类(白名单) · 单价 · 单位 · 场所类型(农贸/商超/其他) · 日期 · 可选备注`。
- 展示：同城同品 **中位数优先**，附样本数 n；极端值进审核。
- 激励：排行/贡献徽章可缓；**先反作弊**（同 IP 限频、设备指纹弱、验证码）。

#### 市场结论

| 项 | 做 / 缓 / 不做 |
|----|----------------|
| 四书签 + 每书 ≤8～12 主标的 | **做** |
| 民生 UGC 试点 1～3 城 | **做** |
| 行情报警推送 / 策略信号 | **缓** |
| 跟投、价差套利工具、合约下单深链 | **不做** |
| UGC 改外汇/金价/原油 | **不做** |
