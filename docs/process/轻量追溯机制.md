## 1. 四轨

| 轨 | 文件名 | 目录 | 管什么 |
|----|--------|------|--------|
| **需求归档** | 需求归档-YYYY-MM-DD-主题.md | docs/requirements/ | 拍板：要做什么 / 不做 / 验收 |
| **错误归档** | 错误归档-YYYY-MM-DD-主题.md | docs/records/ | 弯路与缺陷 |
| **更新记录** | 更新归档-YYYY-MM-DD-主题.md + 用户可见更新说明 | docs/records/ | 交付说明；用户可见以 更新说明（本仓约定） 为准 |
| **重要会话** | 会话归档-YYYY-MM-DD-主题.md | docs/records/ | 重要讨论，防只留聊天 |

模板：同目录 _模板-*.md。新建：

`powershell
python scripts/new_archive.py req 主题短名
python scripts/new_archive.py err 主题短名
python scripts/new_archive.py upd 主题短名
python scripts/new_archive.py sess 主题短名
`

## 2. 触发（摘要）

- **需求**：新功能/改契约/改主路径；或用户说归档需求  
- **错误**：排查 ≥30min 或 ≥2 弯路；修完填弯路对照  
- **更新**：用户可感知升版 → 更新说明必写；非琐碎再写更新归档  
- **会话**：多拍板点 / 长探索 / 用户说归档会话；拍板后决策进需求档  

## 3. 明确不做

- wikimap 九阶段命令链、强制 ISS 台账  
- 琐碎 typo 硬开错误/需求档
