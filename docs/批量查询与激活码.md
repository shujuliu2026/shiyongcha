# 批量联行号 · 激活码

深挖 15 万支行编码数据价值：支持多行批量查询与 CSV 导出；批量接口需激活码。

## 套餐

| 套餐 | 说明 | 扣费 |
|------|------|------|
| **按次** (`once`) | 默认 100 次（可签发时改 `--quota`） | 每批按行数扣次 |
| **包月** (`month`) | 激活起 31 天 | 期内不限次（受单次行数上限） |
| **包季** (`quarter`) | 激活起 93 天 | 同上 |

售卖与兑付走**客服微信**（`CS_WECHAT`），核实后发放激活码。

## 用户流程

1. 打开 `/bank/batch`
2. 添加客服微信，说明要「按次 / 包月 / 包季」
3. 获得激活码 → 页内激活 → 粘贴多行查询 → 导出 CSV

单条查询 `/bank` 走免费日额度（`FREE_SINGLE_DAILY`，默认 30/IP）；有许可证时不扣免费额度。

## 运营签发

```powershell
cd D:\projects\tool
# 可选：先把 CS_WECHAT 写进 .env
npm run license:issue -- --plan once --quota 100 --note "客户A"
npm run license:issue -- --plan month --note "包月B"
npm run license:issue -- --plan quarter --note "包季C"
```

激活码写入 `data/licenses.json`（已 gitignore）。通过客服微信发给用户。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/license/plans` | 套餐 + 客服文案 |
| POST | `/api/v1/license/activate` | `{ "code": "SY-...." }` → token |
| GET | `/api/v1/license/status` | `?token=` 或头 `X-License-Token` |
| POST | `/api/v1/info/bank/cnaps/batch` | `{ "text": "多行..." }`，需 token |

## 环境变量

见根目录 `.env.example`：`CS_WECHAT`、`CS_TIP`、`FREE_SINGLE_DAILY`、`BATCH_MAX_LINES`。
