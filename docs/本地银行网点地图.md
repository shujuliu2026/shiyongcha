# 本地银行网点 · 地图接入

联行表无门牌/坐标。实用查通过 **地理编码** 写入缓存，再在 `/local-bank` 用 Leaflet 打点。

## 使用

1. [高德开放平台](https://console.amap.com/dev/key/app) 创建 **Web 服务** Key  
2. 根目录 `.env`：

```env
AMAP_WEB_KEY=你的key
```

3. 批量编码（约 300 家，有速率间隔）：

```powershell
cd D:\projects\tool
npm run geocode:linyi-banks
# 试跑前 20 条： npm run geocode:linyi-banks -- --limit 20
```

4. 打开 http://127.0.0.1:5176/local-bank → 地图标注；单条也可点「定位」。

缓存文件：`data/linyi-bank-geo.json`（按联行号）。

**无 Key**：批量脚本会用 **区县中心近似点**（`provider: district_approx`），地图可立刻铺开；配置高德后 `--force` 再跑即可换成精确 POI。

地图图例：绿色=精确/高德缓存，橙色=区县近似（同坐标会轻微散开以免重叠）。已排除安徽阜阳「临沂商城」网点等外地误命中。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/local/bank/geo/status` | 是否配置 Key、缓存点数 |
| GET | `/api/v1/local/bank/geo/points` | 全部缓存点 |
| POST | `/api/v1/local/bank/geo/geocode` | `{ cnaps, name, city? }` 单条编码并落盘 |
| GET | `/api/v1/info/bank/cnaps?city=临沂&geo=1` | 结果附带 `lat/lng`（若已缓存） |

高德返回 GCJ02，入库前转为 **WGS84**，底图用 OSM/Carto（与台风页 Leaflet 一致）。「高德搜」外链仍可打开高德 App/网页核对。

## 无 Key

会回落 **Nominatim**（慢，请勿批量猛刷）。地图可显示，精度不如高德。
